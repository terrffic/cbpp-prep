## 1. 怎么跑

```bash
# 前置：node 18+；jsdom 已装在 WorkBuddy 的 node workspace，
# 脚本通过 JSDOM_PATH 环境变量或默认路径定位（见各脚本头部）
```

## 5. 已知局限

1. **没有真机/浏览器截图验证**：本机 Chrome headless 无法出图（返回 NO FILE），手机端与桌面端的视觉验证退化为 CSS 结构与计算属性检查。这是环境限制，不是"已通过"。
2. **jsdom 不是真浏览器**：布局、滚动、requestAnimationFrame 时序与真实浏览器存在差异；`scrollIntoView`、`confirm` 在测试中被 stub。
3. **没有覆盖率统计**（未接 istanbul）：断言是行为级而非行级，不能报"代码覆盖率 8x%"。
4. **难度与认知层次是启发式**：脚本注释里写明判定规则，属结构指标，不等于实测难度。
