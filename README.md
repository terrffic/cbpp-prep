# CBPP 备考中心（业务流程管理专家认证）

依据 ABPMP《BPM CBOK®》4.0 与 2025 版《CBPP Examination Handbook》官方考试蓝图制作的交互式备考工具，纯前端单文件实现，无需安装、双击即用。

## 官方考试信息

| 项目 | 内容 |
|---|---|
| 题量 | 140 道单选题 |
| 时长 | 180 分钟（3 小时） |
| 及格线 | 70%（答对 98 题） |
| 语言 | **全英文**（本系统的题干与选项同样为英文，与真题一致） |
| 组卷 | 按 9 大知识域蓝图比例，题目随机乱序 |

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | **唯一入口 · 目录页**：一页列出九个知识域、五套全真卷、单章模考/错题本/统计，点一行直达对应内容 |
| `CBPP备考中心.html` | **主体应用**：精讲（含思维导图全树）+ 分章练习 + 五套全真卷 + 错题本，两个 Tab 切换 |
| `CBPP考点思维导图.html` | 单文件版 · 只要思维导图与分章练习时使用（内容与主站一致） |
| `CBPP模拟考试系统.html` | 单文件版 · 只要模拟考试时使用（内容与主站一致） |

## 导航：一页目录，点一下就到

整个站点只有**一个入口页**，且所有内容都摊在这一页上，不需要先选模块再选内容：

1. **目录页 `index.html`**：上半部分是「精讲与分章练习」，按九大知识域逐行列出，每行右侧一个「练习」按钮；下半部分是「全真模拟考试」，五套卷逐行列出发，右侧「开始」直接开考；底部三块小卡分别是单章模考、错题本、练习统计。**每一行点一次就进到目标位置**。
2. **进到内容后**：页面顶部只有「🏠 ← 目录」一个返回入口（另有页内的学习/考试两个 Tab 相互切换）；答题页有「← 列表」回卷列表，成绩单有「← 返回模考列表」，解析页有「← 返回成绩单」——只退一级，不会连跳。
3. **深链参数**（可直接收藏或分享）：

| 链接 | 直接到达 |
|---|---|
| `CBPP备考中心.html#domain3` | 第 3 知识域「流程分析」精讲，自动展开 |
| `CBPP备考中心.html#drill3` | 第 3 章练习，弹出第一题 |
| `CBPP备考中心.html#outline` | 完整知识树，全部层级展开 |
| `CBPP备考中心.html#paper3` | 第 3 套全真卷，直接开考（180 分钟计时） |
| `CBPP备考中心.html#chapter` | 单章模考选题区 |
| `CBPP备考中心.html#wrong` | 错题本 |
| `CBPP备考中心.html#stats` | 练习统计 |

开考后地址栏会归一到 `#exam`，刷新时停在卷列表并从横幅继续，不会重开一张新卷。

**界面全双语**：标题、按钮、表头、图例、提示语均以「中文 + 英文小字」呈现；考试页与练习弹窗的题面保持纯英文（可切中英对照），解析为中英双语。

## 功能总览

> **语言说明**：CBPP 正式考试为英文卷，因此本系统的 **311 道模考题与 36 道分章练习全部采用英文题干与英文选项**（与考试语言一致，帮助建立英文题感）；答题时可随时点击「🌐 中英对照」叠加中文翻译；**解析为中英双语**。思维导图的 115 个节点均为双语：中文精讲 + 英文标题与英文要点（EN 段落）。

### 📚 考点思维导图（学习模块）
- 九大知识域四级结构（章 → 节 → 知识点 → 细讲），任意节点点开精讲卡
- 全部节点双语：中文标题 + 英文标题，精讲卡底部附英文要点（EN）
- 每章「★ 英文缩写速查」表格（57 条：BPMN / SIPOC / DPMO / PCF / RPA / BRMS 等，均标注考点）
- 关键词搜索定位、全部展开 / 收起
- 36 道分章练习（英文题面，可切中英对照），即时判分 + 双语解析

### 🎯 全真模拟考试（考试模块）
- **五套全真卷**：每套 140 题 / 180 分钟，各知识域题量严格按官方蓝图分配（9/17/14/15/15/14/17/19/20），全卷乱序，卷间约半数题目不同
- **311 题英文题库**：以情境应用题为主（对齐真题难度），含 DPMO / PCE / FPY 计算题与工具匹配题
- 单章专项模考、错题重做
- 考场级体验：倒计时（最后 5 分钟红色警告）、答题卡导航、标记复查、中途刷新可恢复进度、到时自动交卷
- 成绩单：按知识域正确率对照 70% 及格线，薄弱章节一眼可见
- 答案解析回顾：英文解析 + 中文解析对照
- 错题本 + 考试历史（localStorage 本地持久化）

## 使用方法

1. 下载整个仓库（`index.html`、`CBPP备考中心.html`，以及两个单文件版，放在同一目录）
2. 用浏览器（Chrome / Edge）打开 `index.html` 即可，无需联网；也可只带 `CBPP备考中心.html` 一个文件使用
3. 学习路径建议：思维导图精讲 → 分章练习 → 五套全真模考 → 错题重做，模拟成绩稳定在 75% 以上再上考场
