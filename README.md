# CBPP 备考中心（业务流程管理专家认证）

依据 ABPMP《BPM CBOK®》4.0 与 2025 版《CBPP Examination Handbook》官方考试蓝图制作的交互式备考工具，纯前端单文件实现，无需安装、双击即用。

## 官方考试信息

| 项目 | 内容 |
|---|---|
| 题量 | 140 道单选题 |
| 时长 | 180 分钟（3 小时） |
| 及格线 | 70%（答对 98 题） |
| 语言 | **全英文**（本系统的题干与选项同样为英文，与真题一致） |
| 组卷 | 按 9 大知识域蓝图比例，题目随机乱序 |

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | **唯一入口**：三张模块卡片（思维导图 / 精讲与分章练习 / 全真模拟考试），点选即进入对应模块 |
| `CBPP考点思维导图.html` | 模块 01 · 考点思维导图：九大知识域四级展开精讲 + 缩写速查 + 36 题分章练习 |
| `CBPP备考中心.html` | 模块 02 · 精讲与分章练习：学习地图 + 分章练习 + 错题统计；顶部第二个 Tab 内嵌模拟考试，方便连续使用 |
| `CBPP模拟考试系统.html` | 模块 03 · 全真模拟考试：五套全真卷 + 单章模考 + 错题本 |

## 导航：一个入口，逐级返回

只有一个入口页，不再有「主页 + 推荐入口」两层：

1. **唯一入口 `index.html`**：打开后直接看到三张模块卡片，选哪个进哪个；卡片上标明该模块的内容与规模（9 大知识域 / 36 题练习 / 5 套全真卷等）
2. **进入模块后（第二级）**：每个页面顶部都有深色吸顶导航条，最左侧固定「🏠 ← 返回首页」，随时回到入口重新选模块；右侧是另外两个模块的快捷入口（同级切换，不用先回首页）
3. **模块内部再下一级（第三级）**：答题页有「← 列表」返回试卷选择（进度已保存，可从横幅继续）；成绩单有「← 返回模考列表」；解析回顾有「← 返回成绩单」；错题本有「← 返回模考列表」——每一级都能退回上一级
4. **URL 直达**：`CBPP备考中心.html#study` 进入学习地图、`#exam` 进入模拟考试；当前 Tab 会写进地址栏，刷新后停在原处

**界面全双语**：标题、按钮、表头、图例、提示语均以「中文 + 英文小字」呈现；考试页与练习弹窗的题面保持纯英文（可切中英对照），解析为中英双语。

## 功能总览

> **语言说明**：CBPP 正式考试为英文卷，因此本系统的 **311 道模考题与 36 道分章练习全部采用英文题干与英文选项**（与考试语言一致，帮助建立英文题感）；答题时可随时点击「🌐 中英对照」叠加中文翻译；**解析为中英双语**。思维导图的 115 个节点均为双语：中文精讲 + 英文标题与英文要点（EN 段落）。

### 📚 考点思维导图（学习模块）
- 九大知识域四级结构（章 → 节 → 知识点 → 细讲），任意节点点开精讲卡
- 全部节点双语：中文标题 + 英文标题，精讲卡底部附英文要点（EN）
- 每章「★ 英文缩写速查」表格（57 条：BPMN / SIPOC / DPMO / PCF / RPA / BRMS 等，均标注考点）
- 关键词搜索定位、全部展开 / 收起
- 36 道分章练习（英文题面，可切中英对照），即时判分 + 双语解析

### 🎯 全真模拟考试（考试模块）
- **五套全真卷**：每套 140 题 / 180 分钟，各知识域题量严格按官方蓝图分配（9/17/14/15/15/14/17/19/20），全卷乱序，卷间约半数题目不同
- **311 题英文题库**：以情境应用题为主（对齐真题难度），含 DPMO / PCE / FPY 计算题与工具匹配题
- 单章专项模考、错题重做
- 考场级体验：倒计时（最后 5 分钟红色警告）、答题卡导航、标记复查、中途刷新可恢复进度、到时自动交卷
- 成绩单：按知识域正确率对照 70% 及格线，薄弱章节一眼可见
- 答案解析回顾：英文解析 + 中文解析对照
- 错题本 + 考试历史（localStorage 本地持久化）

## 使用方法

1. 下载整个仓库（或至少 `index.html` 与三个 HTML 模块文件，放在同一目录）
2. 用浏览器（Chrome / Edge）打开 `index.html` 即可，无需联网；也可直接打开任一模块文件单独使用
3. 学习路径建议：思维导图精讲 → 分章练习 → 五套全真模考 → 错题重做，模拟成绩稳定在 75% 以上再上考场
