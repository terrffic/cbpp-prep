# CBPP 备考中心（业务流程管理专家认证）

依据 ABPMP《BPM CBOK®》4.0 与 2025 版《CBPP Examination Handbook》官方考试蓝图制作的交互式备考工具，纯前端单文件实现，无需安装、双击即用。

## 官方考试信息

| 项目 | 内容 |
|---|---|
| 题量 | 140 道单选题 |
| 时长 | 180 分钟（3 小时） |
| 及格线 | 70%（答对 98 题） |
| 语言 | **全英文**（本系统的题干与选项同样为英文，与真题一致） |
| 组卷 | 按 9 大知识域蓝图比例，题目随机乱序 |

## 文件说明

| 文件 | 用途 |
|---|---|
| `CBPP备考中心.html` | **主入口**（推荐）：学习地图 + 模拟考试一体化，顶部 Tab 切换 |
| `CBPP考点思维导图.html` | 考点思维导图单文件版：九大知识域四级展开精讲 |
| `CBPP模拟考试系统.html` | 模拟考试单文件版：五套全真卷 + 单章模考 |

## 功能总览

> **语言说明**：CBPP 正式考试为英文卷，因此本系统的 **311 道模考题与 36 道分章练习全部采用英文题干与英文选项**（与考试语言一致，帮助建立英文题感）；答题时可随时点击「🌐 中英对照」叠加中文翻译；**解析为中英双语**。思维导图的 115 个节点均为双语：中文精讲 + 英文标题与英文要点（EN 段落）。

### 📚 考点思维导图（学习模块）
- 九大知识域四级结构（章 → 节 → 知识点 → 细讲），任意节点点开精讲卡
- 全部节点双语：中文标题 + 英文标题，精讲卡底部附英文要点（EN）
- 每章「★ 英文缩写速查」表格（57 条：BPMN / SIPOC / DPMO / PCF / RPA / BRMS 等，均标注考点）
- 关键词搜索定位、全部展开 / 收起
- 36 道分章练习（英文题面，可切中英对照），即时判分 + 双语解析

### 🎯 全真模拟考试（考试模块）
- **五套全真卷**：每套 140 题 / 180 分钟，各知识域题量严格按官方蓝图分配（9/17/14/15/15/14/17/19/20），全卷乱序，卷间约半数题目不同
- **311 题英文题库**：以情境应用题为主（对齐真题难度），含 DPMO / PCE / FPY 计算题与工具匹配题
- 单章专项模考、错题重做
- 考场级体验：倒计时（最后 5 分钟红色警告）、答题卡导航、标记复查、中途刷新可恢复进度、到时自动交卷
- 成绩单：按知识域正确率对照 70% 及格线，薄弱章节一眼可见
- 答案解析回顾：英文解析 + 中文解析对照
- 错题本 + 考试历史（localStorage 本地持久化）

## 使用方法

1. 下载 `CBPP备考中心.html`
2. 用浏览器（Chrome / Edge）打开即可，无需联网
3. 学习路径建议：思维导图精讲 → 分章练习 → 五套全真模考 → 错题重做，模拟成绩稳定在 75% 以上再上考场
