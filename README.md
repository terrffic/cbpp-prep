# CBPP 备考中心（业务流程管理专家认证）

**在线访问：https://terrffic.github.io/cbpp-prep/** ｜ 内容提交 `0273adc`（Pages 构建 `built`，四个入口 HTML 线上 SHA-256 与入库内容逐一一致；此后的文档提交不改 HTML，以文件哈希为准，见 `reports/F_deploy.md`）

依据 ABPMP《BPM CBOK®》4.0 的知识域划分与 2025 版《CBPP Examination Handbook》公布的考试蓝图制作的**交互式备考工具**。纯前端、单文件、无需安装：线上直接打开上面的链接，本地双击 `index.html` 即用。

> **性质声明**：本系统是**第三方学习工具**，不是 ABPMP 官方产品，题目不是真题，也不宣称与真实考试在难度或内容上一致。官方手册明确说明：通过分数由心理测量学方法确定，**未公布固定百分比**；本系统界面上的 70% 是**训练参考线**，不是官方及格线。

## 题库现状（版本标记 `2026-10-rev3`）

- 模考题库 **323 题**，覆盖 9 个知识域、官方蓝图 19 个二级领域（每个二级领域 ≥5 题）。
- 分章练习 36 题（与模考题库共用题干，属同一内容源的另一种取用方式）。
- 每套卷 140 题，域分布严格按蓝图 9/17/14/15/15/14/17/19/20；卷内不重复。
- 正确答案在 A/B/C/D 上分布为 25% / 24% / 25% / 25%，已消除「答案集中在 A」的猜题空间。
- **五套卷并非彼此独立**：323 题要填 5×140 个答题位，两两重合 39%–49%（结构性下限约 44%）。因此第 1、2 套标为「基准卷」，第 3–5 套标为「强化练习卷」，界面如实显示与第 1 套的实际重合比例。
- 题库版本号变化后，旧成绩标记为「旧题库 / legacy」，不计入最高分，也不与新版本混算。

## 数据与隐私

所有答题记录只存在浏览器 `localStorage`（键名 `cbpp_exam_v1`），不上传任何服务器。清空浏览器数据会丢失历史成绩。
